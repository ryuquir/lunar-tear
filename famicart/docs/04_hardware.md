# 04. ハードウェア（Pico / Pico 2 向け 27 ピン構成）

## 部品

| 数量 | 部品 | 役割 |
|---:|---|---|
| 1 | Raspberry Pi Pico（RP2040）または Pico 2（RP2350A） | 本体。Pico 2 推奨（SRAM 520KB） |
| 4 | 74LVC541（8 ビット 3 ステートバッファ、5V トレラント） | CPU A0–7 / CPU A8–14+R/W / PPU A0–7 / PPU A8–13+/RD+/WR |
| 2 | 74LVC245（8 ビットトランシーバ、5V トレラント） | CPU D0–7（DIR = R/W）/ PPU D0–7（DIR = PPU /RD） |
| 1 | 74HC139 または 74LVC139（デュアル 2→4 デコーダ） | 各ポートの /OE 選択（2 ピンで 3 本の /OE を排他制御） |
| 1 | 74LVC1G08（2 入力 AND、単ゲート） | /PPUACC = PPU /RD AND PPU /WR |
| 1 | 74LVC1G07（オープンドレインバッファ）※任意 | /IRQ のプルアップ耐圧確保（GPIO 直のオープンドレイン駆動でも可） |
| - | 3.3V LDO（Pico の 3V3 出力 300mA で足りる）、パスコン 0.1µF ×8 | 電源 |
| - | 抵抗 2 本 + コンデンサ 2 個（RC 2 段）、抵抗 2 本（ミックス） | 拡張音声 |

すべてのバッファは VCC = 3.3V で動作させ、5V 入力は LVC の 5V トレラント入力で受ける。出力 3.3V（VOH ≥ 2.4V）は 2A03/2C02 の入力しきい値（TTL 相当）を満たす（市販フラッシュカートと同じ手法）。

### 音声

```
GP25 (PWM ~246 kHz, 10bit) ─ 2.2k ─┬─ 2.2k ─┬──── 10k ──┐
                                   │        │           ├── 端子 46（音声出力）
                                  10n      10n          │
                                   │        │   端子 45 ─ 10k ┘
                                  GND      GND
```

本体音声（45）と拡張音声を抵抗加算して 46 へ返す。VRC7 実機相当のレベルは `--volume` で調整。

### 電源・その他

- 端子 30（+5V）→ Pico VSYS。端子 1,16（GND）。
- 端子 31（CartridgePresent）: 本体リビジョンによっては 30 と短絡が必要（nesdev 参照）。

## CIRAM タイミングが厳しい場合の代替（ハードウェアミラーリング）

74LVC153（デュアル 4:1 マルチプレクサ）で CIRAM A10 を {PPU A10, PPU A11, L, H} から選び、選択 2 線を RP2040 の空き GPIO で駆動する（素の RP2040 / RP2350B で 2 ピン追加）。ミラーリング変更時だけ GPIO を書くので A10 は組み合わせ回路になり、遅延が約 10 ns に収まる。カートリッジ側ネームテーブル（MMC5 ExRAM、Namco 163、4 画面）を使うタイトルのみ RP2040 が /CE を制御する。

## RP2350B（QFN-80, 48 GPIO）での直結案

CPU 27 + PPU 26 = 53 本 > 48 本なので、データ 8 本だけを 2 個の 74LVC245 で共有（46 本）し、アドレスはバッファ経由で直結（レベル変換のためバッファ自体は必要）。PIO 側はアドレスをワンショットで取り込めるため CPU 応答に約 50 ns の余裕が増える。
