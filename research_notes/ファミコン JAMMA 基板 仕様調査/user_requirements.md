## 1. 部品選定・実装ルール（当初指示）

- 実装は JLCPCB。部品は Basic Parts のみ。
- PCBA に載せる部品は LCSC で豊富な在庫があるもの。
- 手はんだ部品は秋月電子で在庫があるもの。
- 小さい部品は PCBA に任せる。
- 特殊な部品や調達しにくい部品は極力避ける。
- パーツの種類や点数は減らす。
- 目指すのは「設計できる」ではなく「実際に作れる安価な」基板。

## 2. 製品要求（当初指示）

- ゲームセンター用のアーケード基板。JAMMA 端子。
- ファミリーコンピュータ（日本販売品）がベース。主要部品は CPU と PPU のみをファミコンから取り外して移植する。
- もしくは Raspberry Pi 等を実装し、CPU・PPU をエミュレートさせる。両方を選択できること。
  ソケットを実装しておき、ラズパイを挿すか CPU/PPU を挿すかを選び、DIP スイッチ等でどちらを選んだか設定する。
- ファームウェアの更新は USB 等で簡単に行えること。
- 全部を基板実装メーカーに実装してもらい、負担を減らす。
- DIP スイッチで次の2方式を選べること。
  - 通常制: コインスタート、残機ゼロでゲームオーバー。
  - 時間制: コイン投入後、指定された時間だけ遊べる（市販カセットを挿した場合にハードウェア側で設定できるようにするため）。
  - 専用開発のゲームカートリッジは自前で制御できるので通常モードでよい。

## 3. 入力マッピング（2026-11-10 改訂・現行）

ユーザー指示の原文:

> JAMMAの配線として１P.２P共に上下左右とABボタンはそのまま、コイン投入はセレクト、スタートボタンはスタートとしてください、Cボタンは上下同時押し、Dボタンは左右同時押しをもって対応する設計にしてください。

### 3.1 対応表

ファミコンのパッドは A, B, SELECT, START, 上, 下, 左, 右 の順に1ビットずつ読み出される（ビット0〜7）。

| JAMMA の入力 | 1P 側ピン | 2P 側ピン | ゲームから見える入力 |
|---|---|---|---|
| レバー上 | 18 | V | そのパッドの「上」（ビット4） |
| レバー下 | 19 | W | そのパッドの「下」（ビット5） |
| レバー左 | 20 | X | そのパッドの「左」（ビット6） |
| レバー右 | 21 | Y | そのパッドの「右」（ビット7） |
| ボタン1（A） | 22 | Z | そのパッドの「A」（ビット0） |
| ボタン2（B） | 23 | a | そのパッドの「B」（ビット1） |
| ボタン3（C） | 24 | b | そのパッドの「上」と「下」を同時に押下 |
| ボタン4（D） | 25 | c | そのパッドの「左」と「右」を同時に押下 |
| スタート | 17 | U | そのパッドの「START」（ビット3） |
| コイン投入 | 16（コイン1） | T（コイン2） | そのパッドの「SELECT」（ビット2） |

### 3.2 この表を作るうえで置いた前提（ユーザー未確認）

- ボタン名は日本の業務用筐体の慣例どおり、JAMMA のボタン1=A、ボタン2=B、ボタン3=C、ボタン4=D と読んだ。
- ボタン4（ピン25／c）は JAMMA の正式規格外で、慣例的に使われている拡張割り当てである。
- コイン2（ピンT）は 2P 側パッドの SELECT に入れると読んだ（「1P・2P共に」の指示による）。
- 当初指示にあった「1P/2P スタート=上下左右同時押し」は、スタートが START に直結になったため廃止と読んだ。
- 当初指示にあった「DIP スイッチでコインを START にも切り替えられる」を残すかどうかは未確認。

### 3.3 このマッピングから生じる設計上の帰結（推論）

- **C・D を押している間は、その軸のレバー入力がゲームから見えなくなる。**
  C を押すと上下が両方押下になるので、レバーが上・下・中立のどれかを区別できない。D は左右について同様。
  専用ゲームは、C・D を「その軸のレバー入力を同時に必要としない操作」に割り当てる必要がある。
- **市販カセットでは C・D が誤動作の原因になる。**
  上下同時・左右同時は、実物のパッドでは起こらない入力で、既知の不具合が複数のソフトにある
  （調査ノート famicom_hardware.md の「同時押しに関する既知の挙動」を参照）。
  市販カセットを動かすときは C・D を無効にする DIP スイッチが必要。
- **2P 側の START・SELECT は、初代ファミコンには存在しないビットである。**
  初代機の II コントローラは、この2ビットが常に「押されていない」と読める。
  本基板では AV ファミコンや NES と同じく 2P 側にも実ビットを出す。初代機前提の市販ソフトの大半はこれを読まない。
- **コインの信号はそのまま渡さず、整形して SELECT に出す必要がある。**
  コインスイッチの閉じる時間は機構によってまちまちで、1フレームより短いとゲームが取りこぼす。
  任天堂 VS. システムの実機は 2.5〜4 フレーム幅だった（coin_op_precedents_and_legal.md 参照）。
  複数枚の連続投入は待ち行列にして、1枚ずつ間隔を空けて出す。
- **市販カセットではコイン=SELECT、スタート=START が本来の意味で働く。**
  SELECT はタイトル画面のカーソルを動かし、START はプレイ中のポーズになる。
  時間制モードでコインを SELECT として出すかどうかは、別途決める必要がある。
- **ファミコンのパッドは B が左、A が右に並ぶが、筐体のボタンは左から A, B の順である。**
  市販ソフトの操作感を実機に合わせたい場合に備え、A と B を入れ替える DIP スイッチを用意する価値がある。

### 3.4 当初の入力仕様（2026-11-10 の改訂で置き換え）

- セレクトボタンをコインシューターとする（DIP スイッチでスタートボタンをコインシューターにもできる）。
- 1P コントローラーの上下左右同時押しを 1P スタート、2P コントローラーの上下左右同時押しを 2P スタートとする
  （特殊仕様として DIP スイッチで設定できる）。
