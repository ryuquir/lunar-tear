## 1. 確定事実

### 1.0 この章の用語と確度の記号

- **PCBA**: 基板製造と部品実装をまとめて請け負うサービス。JLCPCB では Economic（廉価版）と Standard（標準版）の 2 区分がある。
- **装填料（Feeder Loading fee）**: 部品をマウンタ（自動実装機）の供給装置に取り付ける人件費。部品の種類ごとに注文 1 回あたりで課金される。
- **Basic 部品**: マウンタに常時装填されている部品。JLCPCB の部品ライブラリの API 上は `componentLibraryType` が `base`。
- **Preferred Extended 部品**: 以前は Basic だった部品群。API 上は `componentLibraryType` が `expand` で、かつ `preferredComponentFlag` が true。jlcpcb.com の画面では、検索フィルタの名前が「Promotional Extended」で、部品の詳細ページのバッジは単に「Extended」と表示される。
- **Extended 部品**: 上の 2 つ以外のすべての部品。
- **THT**: スルーホール部品（リード線を基板の穴に通してはんだ付けする部品）。JLCPCB ではウェーブはんだ付けまたは手はんだで実装する。部品ライブラリで実装方式が「Wave Soldering」と表示される部品が、これに当たる。
- **ENIG**: 無電解ニッケル下地の金めっきによる表面処理。JLCPCB で金フィンガーを金にする唯一の方法。
- **金フィンガー**: カードエッジ端子として基板の縁に並べる金めっきのパッド。JAMMA 端子はこれで作る。
- **面取り（ベベル）**: 金フィンガー側の基板の縁を斜めに削る加工。
- **セットバック**: 面取りで削られる範囲を避けるため、基板の先端からパッドまでに空ける銅のない距離。
- 確度の記号: **確認済** は、独立した 2 つ以上の出典があるもの、またはライブデータ（JLCPCB の API、見積画面、秋月の商品ページ）やデータシートで直接確認したもの。**単一出典** は、出典が 1 つだけのもの、または古い巡回データ（CDFER の DB。最新の取得日は 2026-10-28 頃）だけに基づくもの。**未確認** は、確かめられていないもの。
- 注意: CDFER、jlcparts、jlcsearch はどれも同じ巡回データの系統なので、互いに独立した出典ではない。JLCPCB 自身と独立しているのは、LCSC の API（在庫と価格のみ）だけである。

#### 1.1.4 スルーホール部品の扱い

| 事実 | 確度 |
|---|---|
| JLCPCB は THT の実装と、SMD と THT の混載に Economic・Standard の両方で対応する。THT はウェーブはんだ付けで実装し、使わない穴にははんだが入らないよう保護する | 確認済（能力表の FAQ） |
| 部品ライブラリで「wave soldering」と表示される部品は人手で実装する。費用は手はんだ人件費 $3.50〜$3.58／注文 + $0.0164／ジョイント（旧 FAQ では $0.0173）。製作日数は SMT の日数 + 1 日 | 確認済 |
| THT が可能なのは「as long as the part is listed for through-hole assembly in the parts library」の部品に限る | 単一出典（公式ブログ） |
| THT 部品に装填料がかからないかどうか | **未確認**（第1次調査は「かからない」としたが、公式の明記は見つからなかった） |
| Basic 部品の中に THT 部品は 1 つもない（Basic 351 件はすべて SMD） | 確認済 |
| IC をソケットに載せた状態で納品させる「積み重ね部品」は可能。両方を BOM と CPL（部品座標表）に入れ、IC の座標をソケットから 0.2mm 以上ずらして登録し、備考に「need to put the B part on the A part」と書く。通常は手作業なので追加の人件費がかかる | 確認済 |

#### 1.3.5 再検証で分類・在庫・掲載の扱いが変わった部品

- **分類が変わった部品はない**。第1次調査の Basic・Preferred Extended・Extended の判定は、JLCPCB 自身の API ですべて一致した（確認済）。
- **「ライブラリに無い」から「掲載はあるが Extended で在庫 0」に変わった部品**: 74HC368（C5635 など 24 件）、74HCU04（C3272681 など。在庫ありは PDIP の C2867641 の 79 個だけ）、6116/6264/62256 系 SRAM（C9900151975、C261871、C32483、AS6C62256 系 16 件、CY62256 系 91 件）。使えないという結論は変わらない。
- **在庫が実質ゼロになった部品**: 74HC574 C16501（41,694 → 4）、74HC4051 C9386（23,555 → 0）、ULN2803ADWR C9683（Preferred だが在庫 0）。
- **在庫が増えた部品**: IS61LV256AL C412837（18 → 2,358）。
- **同じ品名で C 番号ごとに分類が違う部品**: BAT54S は C7420333 が Preferred、C47546（BAT54S,215）が Extended。ULN2803 は C9683 が Preferred（在庫 0）、C845537 が Extended。BOM には品名ではなく C 番号で書くこと。
- **画面表示の注意**: jlcpcb.com の部品行と詳細ページのバッジは、Preferred Extended でも「Extended」としか表示されない。Preferred かどうかは検索画面の「Promotional Extended」フィルタか、API の `preferredComponentFlag` で確かめる必要がある。

## 4. ユーザー要求への影響

この章では、出典で確かめた事実と、筆者の推論を分けて書く。推論には「推論」と付ける。

### 4.1 「部品は Basic Parts のみ」（1 章）

**事実**
- Basic は 351 件で、マイコン、SRAM、USB 端子、音声アンプ、DIP スイッチ、ソケット、コネクタ、電解コンデンサ、ポリスイッチ、21.47727MHz 水晶、74HC14・74HC595 以外のロジック、THT 部品は 1 つもない。
- JAMMA の金フィンガーを本体基板に作ると、実装は Standard しか選べない。Standard では Basic にも 1 種類 $1.53 の装填料がかかる。

**推論**
- Basic だけで基板を完成させることはできない。Basic でない部品は、秋月の手はんだ品か、ドナー機からの流用で補うことになる。これは「全部を基板実装メーカーに実装してもらう」（2 章）という要求とぶつかる。
- 一体基板（Standard）では、「Basic のみ」は装填料を 1 円も節約しない。節約になるのは種類数の削減だけである。
- 選択肢と費用（1.8.2 の試算、10 枚の場合の 1 枚あたり）:
  - A（一体基板、実装は Basic のみ、残りは秋月の手はんだ）約 ¥5,170。手はんだが多い。
  - B（一体基板、Basic + Preferred + Extended をすべて実装）約 ¥6,800（SRAM 流用の B' は約 ¥5,420）。手はんだは Pico 2 だけ。
  - C'（エッジ基板を分離し、本体を Economic・Basic のみで実装）約 ¥4,350。最安だが、基板間の約 40 本の接続を手で作る必要があり、嵌合の信頼性を負う。
- **推奨（推論）**: 規則を「Basic を優先し、Basic にないものは Preferred Extended、さらにない場合は JLCPCB で在庫が豊富な Extended を許す。ただし部品の種類数を最小にする」に改めるよう、ユーザーに確認を求める。理由は 3 つある。(1) 一体基板では Basic のみでも装填料が減らない。(2) 手はんだを減らすことがユーザーの「全部を実装してもらう」「負担を減らす」に直結する。(3) B と A の差は 10 枚で 1 枚あたり約 ¥1,600 で、そのうち SRAM 流用で約 ¥1,400 縮まる。ユーザーが費用を最優先し、基板間の手配線を受け入れるなら C' を選ぶ。

### 4.2 「LCSC で豊富な在庫」「秋月で在庫があるもの」「特殊な部品は避ける」（1 章）

**事実**
- 在庫が少ない、または実質ゼロの部品: 74HC574 C16501（4）、74HC368（0）、74HCU04D（0）、74HC4051 C9386（0）、ULN2803ADWR C9683（0）、旧型 SRAM（0）、475Ω C228851（3）、ED60BGFBK（299）、IS62C256AL（2,548）、21.47727MHz 水晶（C5289705 以外は 34〜190）、秋月の Si5351A モジュール（10 セット）、Pico 2 H（53）、USB Type-C 16P 114356（209）。
- 秋月にないもの: 21.47727MHz 水晶、60P カード端子、DIP 並列 SRAM、74HC139、74HC368、CD4021、74HCT の DIP。

**推論**
- 21.47727MHz 水晶は C5289705（在庫 2,648）に統一し、他の 9 品は代替候補として BOM に記録する。
- 74HC368・74HC574・74HC139・CD4021 は使わない回路にする（74HC368 は 74HC240 系や 74HC125 + インバータ、74HC139 は 74HC138、74HC574 は 74HC273 または 74HC373/573、CD4021 は 74HC165 かマイコンで代替）。
- 60 ピン端子は「特殊な部品」に当たる。JLCPCB で実装できる ED60BGFBK を第一候補とし、試作で純正カートとの嵌合を確かめる。だめならドナー機のコネクタ流用を第二候補とする。
- Si5351A モジュールは在庫 10 で、量産の前提にはできない。

### 4.3 CPU/PPU の実チップとラズパイの両方を選べること、ソケット実装（2 章、5 章）

**事実**
- DIP-40 の丸ピンソケットは秋月で ¥110（在庫 3,491）、JLCPCB では C2332（Extended、THT、在庫 9,994、$0.1264）がある。JLCPCB がウェーブで実装できるかは未確認。
- IC をソケットに載せて納品させることは可能だが、手作業の追加人件費がかかる。
- Pico 用ピンソケット（左右セット）は秋月で ¥250〜¥300。ピンヘッダは Basic にない。

**推論**
- ソケット類は THT で Basic にないので、「Basic のみ」を守る限り秋月品を手はんだすることになる。JLCPCB に実装させるなら、C2332 などが Wave Soldering 対応かを 3.1 の 4 番で確かめる。
- 取り外した CPU/PPU は利用者がソケットに挿す前提にし、JLCPCB の「積み重ね部品」は使わない（ドナー部品を JLCPCB に送れないため）。
- 実チップとラズパイのどちらを挿したかの設定は、要求の 2 章では今も「DIP スイッチ等」となっている。ソフトウェア切り替えの指示（4 章）の対象は動作方式と入力形式なので、この選択を DIP スイッチに残すか、ジャンパーや挿入の自動検出にするかは未確認。DIP スイッチを残す場合は Extended（C99418 など）か秋月品の手はんだになる。

### 4.4 タイマー方式・通常方式（デフォルト形式・特殊形式）と、その切り替えをソフトウェアで行うこと（3 章、4 章）

**事実**
- DIP スイッチは Basic になく、JLCPCB では Extended（C99418 $0.2152、C319050 $0.5269）、秋月では 4P が ¥70〜¥100。
- 設定の保存先として、Preferred の EEPROM（AT24C256C C6482、M24C02 C7562、M24C64 C79988）がある。

**推論**
- 方式・形式用の DIP スイッチはなくす。部品の種類が 1 つ減り、Standard なら装填料 $1.53、Economic なら $3.07 と部品代が浮く。
- 設定はマイコンのフラッシュに保存すれば、EEPROM も不要で種類数が増えない。マイコンのフラッシュを使えない構成のときだけ EEPROM（Preferred）を使う。
- 入力形式の割り当てはファームウェアで行うので、部品表は変わらない。
- 現行の方式・形式は 3 つある（要求の 3 章）。タイマー方式（市販ソフト用。1P スタート→I コンの START、2P スタート→I コンの SELECT、コイン 1・2 は時間の加算のみ、C・D ボタンは不使用）、通常方式のデフォルト形式（コイン→各パッドの SELECT、スタート→START）、通常方式の特殊形式（C→SELECT、D→START、スタート→左右同時、コイン→上下同時）。どれも JAMMA の同じ入力ピンを読み、パッドのビット列への写し方だけが違うので、マイコンがパッドのビット列を作る構成なら、3 つとも追加部品なしで実現できる。逆に、JAMMA 入力をシフトレジスタへ直結する固定配線では、特殊形式の同時押しの合成と方式ごとの割り当て替えができない。
- タイマー方式に固有の部品: コインの整形と待ち行列、残り時間の管理はファームウェアで足りる。残り時間の表示は、映像をマイコンが作り直す構成なら部品不要だが、実チップの PPU の映像をそのまま出す構成では表示手段の部品が別に要る（部品は未検討）。
- 2P 側の START・SELECT を実ビットとして出すこと（要求の 3.7）も、マイコンがパッドのビット列を作るなら部品は増えない。
- 方式・形式の設定経路のうち、テストスイッチ（JAMMA ピン 15）で設定画面を出す方法と USB で書き換える方法は、既存の入力と Type-C 端子を使うので追加部品はない。カートリッジから切り替える方法（OUT1・OUT2 の監視と、$4016 D1・$4017 D1〜D4 への応答）は、マイコンの GPIO とレベル変換の本数が増える可能性がある（本数は未設計）。

### 4.5 マイコンを複数枚使ってよい、将来の更新（5 章）

**事実**
- Pico 2 は秋月で ¥990（在庫 1,462）。Pico 用ピンソケットは ¥250。RP2350A のチップ単体は JLCPCB で Extended（在庫 6,268、$1.2943）、秋月で ¥190（在庫 521）。RP2354A（2MB flash 内蔵）は秋月で ¥250。
- 並列 SRAM は JLCPCB の IS62C256AL（32KB、Extended）と、秋月の M68AF127B（1Mbit、SOP32）しかない。

**推論**
- Pico 2 を 1 枚増やすごとに 1 枚あたり約 ¥1,240 増える。1.8.2 の試算はマイコン 1 枚の前提なので、3 枚構成（映像、入出力、エミュレーション）なら秋月の手はんだ分が約 ¥2,480 増える。
- 将来のメモリ更新に備えるなら、2KB でなく IS62C256AL（32KB）を載せて上位アドレスを配線しておくのが、在庫と分類の面で唯一の現実的な選択肢である（ファミコンの 2KB 相当だけを使う初期状態は、上位アドレスを固定して実現する）。ドナー機の 2KB SRAM を流用すると安いが、容量の余裕はなくなる。費用差は 1 枚あたり約 $8〜9（IS62C256AL ×2）。
- 将来の CPU/PPU の更新には、DIP-40 ソケットを残すことがそのまま差し替えの経路になる。代替モジュールやエミュレーション用マイコンへの切り替えを頻繁に試すなら、秋月のゼロプレッシャーソケット（111744 または 105436、¥250）を使える。エミュレーション側の拡張はファームウェア更新で行うので、4.6 の Type-C 端子の構成がそのまま更新経路になる。
- 拡張用コネクタはピンヘッダ（JLCPCB C2337 または秋月 PH-1x40SG）で用意できる。穴だけ開けておき、部品は付けない（未実装）とすれば、部品の種類も費用も増えない。

### 4.6 USB Type-C からのファームウェア更新（6 章）

**事実**
- Type-C 端子は Basic にない。JLCPCB の C393939（16 ピン、Extended、在庫 340,763、$0.0691）、ESD 保護 USBLC6-2SC6（C21713975、Extended、$0.0392）。秋月の 114356（16 ピン、¥110、在庫僅少 209）、DIP 化基板 113080（¥350、在庫 695）。
- Pico 2 の USB 端子は Micro-B で、USB の信号は 40 ピンの端子列に出ていない（要求仕様ノートの整理）。
- RP2350A や RP2040 を基板に直付けすると、QFN なので X 線検査料（1〜10 個で $1.64／個）がかかる。

**推論**
- 選択肢:
  - (a) RP2350A を直付けし、Type-C 端子を直結する。部品は RP2350A（Extended）、W25Q128JVSIQ（Basic）、12MHz 水晶 C9002（Basic）、C393939（Extended）、USBLC6-2SC6（Extended）。装填料は Standard なら種類ごとに $1.53 で、Extended 3 種の追加費は小さい。手はんだがなくなり、「全部を実装してもらう」に最も合う。リスクは、電源回路などの周辺設計を自分で行う必要があること（周辺部品は未確認）と、X 線検査料。
  - (b) Pico 2 をソケットではなく基板に直接はんだ付けし、裏面のテストパッドを Type-C 端子へつなぐ。手はんだが難しく、量産に向かない。
  - (c) 基板に Type-C 端子を置き、Pico 2 の Micro-B へ短いケーブルで中継する。追加部品は端子とケーブルだけだが、筐体内でケーブルが外れる心配がある。
- **推奨（推論）**: 「Basic のみ」の規則を 4.1 のとおり緩められるなら (a)。Type-C 端子に直結した 1 個の RP2350A が、ほかのマイコンの書き込みも受け持つ構成にすると、Type-C 端子は 1 つで済み、USB ハブ IC も要らない。ハブ IC を載せて各マイコンを USB で直接更新する方式もあるが、ハブ IC の JLCPCB 分類と秋月の在庫は未調査である。規則を緩められない場合は (c) で、端子は秋月の 113080（DIP 化基板、在庫 695）を手はんだする。114356（在庫 209）は在庫が少なく、SMD の手はんだになるので避ける。

### 4.7 全部を基板実装メーカーに実装してもらう、安価に作る（2 章、1 章）

**事実**
- JLCPCB は THT をウェーブはんだで実装できる（部品ライブラリで through-hole 指定の品に限る）。60P の ED60BGFBK と 21.47727MHz の THT 水晶（C18213345、C368768）は「Wave Soldering」と表示される。
- 金フィンガーの追加料金は $0。2 層 150x200mm は 10 枚 $56.40、4 層は $85.50。
- 1 注文の総額が 1 万円を超えると、輸入時に 10% の消費税がかかる。

**推論**
- まず 2 層で設計する（4 層は 5 枚で +$25、主因は技術料 $4 → $25）。
- 5 枚より 10 枚のほうが、1 枚あたり 約 ¥1,600〜¥2,000 安い（A: ¥6,800 → ¥5,170、B: ¥8,830 → ¥6,800）。試作でない限り 10 枚単位で注文する。
- 手はんだを残すと「負担を減らす」に反するので、4.1 の推奨（規則の緩和）と 4.6 の (a) を組み合わせ、利用者の作業を「ドナー機の CPU/PPU をソケットに挿すこと」だけにするのが要求に最も近い。
