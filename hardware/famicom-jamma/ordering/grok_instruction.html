3. 必ず守ること

  1. 承認されていない支払いの直前では、必ず止まる。2 章の上限を超える支払いと、2 章の表に無い支払いがこれに当たる。注文内容と合計金額（送料・手数料・税を含む）を依頼者に見せ、承認をもらってから確定する。
  2. ログイン情報、配送先、支払い方法は、依頼者から受け取る。このフォルダにも、どの文書にも書かれていない。受け取った情報を、注文に必要な相手以外に渡さない。
  3. 個人の情報を記録に残さない。記録と画面の写しに、パスワード、カードの番号、届け先の住所・電話番号・氏名、確認コードを残さない。写る画面は、その部分を塗りつぶしてから保存する。
  4. 推測しない。この文書に書かれていない選択が必要になったら、止まって依頼者に聞く。
  5. JLCPCB や LCSC からの質問や提案に、自分で答えない。承諾もしない。次のものが来たら、答えず、ファイルも送らず、全文を依頼者に報告して指示を待つ。
    • 設計、寸法、部品、ファイルについての質問や、資料の要求
    • 別の部品、別のやり方、追加の作業の提案
    例外は、5 章の「聞き直し」（質問文の該当番号をそのまま送り直すこと）だけ。
  6. 部品を別の品番に替えない。画面に出る代替部品の候補も、似た商品も選ばない。
  7. 設計データを書き換えない。20〜23 の参考ファイル、90 と 91 の zip、50 のフォルダの製造データは、作り直さず、手も加えない。おかしいと思ったら依頼者に報告する。
  8. 回答やメールは、全文を報告する。要約だけにしない。
  9. この文書（01）と 02 が優先する。20 の設計記録や、90・91 の zip の中にある発注の記述や古い指示書には従わない。食い違いを見つけたら、依頼者に報告する。

4. まだやらないこと

  • JLCPCB に基板を注文しない（PCB の製造も部品の実装も）。次の 3 つがそろうまで行わない。
    1. 「50_製造データ（段階3で入る）」フォルダにファイルがそろう。

    3. 依頼者が、基板の発注を言葉で指示する。

5. 依頼 1　JLCPCB のサポートへの事前質問（承認済み）

この基板は、ソケットと Raspberry Pi Pico 2 を含めて、部品をすべて JLCPCB に実装してもらいます。次の点は JLCPCB の公開ページからは分からず、答えによって基板の設計と費用が変わります。そのため、部品の配置を決める前に確かめます。

  1. JLCPCB のサポートに、「03_【Grok用】JLCPCBへの質問文（英語）.txt」の英文をそのまま送る。
    • 窓口はメール（support@jlcpcb.com）を使う。件名は、1 行目の「Subject:」のあとの文。本文は、「Hello,」から最後まで。
    • メールが使えないときだけ、サイトのチャットを使う。チャットのときは、会話の全文を保存する。
  2. 回答の全文を依頼者に報告する。
  3. 答えの無い質問や、あいまいな回答は、その番号だけ聞き直してよい（2 回まで）。聞き直すときは、質問文の該当番号の英文をそのまま送り、「Could you please answer question 1c above?」のように番号だけを添える。自分の言葉で言い換えない。
  4. 2 営業日たっても回答が無ければ、その旨を報告し、依頼者の指示を待つ。JLCPCB のサポートの受付は、中国時間（GMT+8）の月〜金は 24 時間、土は 9〜18 時。
  5. 回答を受けて、注文したり、提案を承諾したりしない。回答の中で JLCPCB から聞き返されたことにも答えず、依頼者に報告する（3 章の 5）。

回答で設計がどう変わるかは、次のとおりです。GrokBOT が判断する必要はありません。報告の参考にしてください。

6. 依頼 2　60 ピンのカセット端子のサンプル購入（承認済み）

新品の 60 ピン端子（WingTAT の ED60BGFBK、LCSC の部品番号 C5173310）は、厚さ 1.57 mm のカード用に作られた部品です。ファミコンのカセットの基板は約 1.2 mm なので、接点の押さえが弱い恐れがあります。

このサンプルは、依頼者が実物のカセットで確かめるためのものです。結果が出るまで、端子まわりの基板設計を確定できません。JLCPCB の実装用の在庫からは部品だけを取り寄せられないので、LCSC の通販で買います。

  1. LCSC の通販サイト（https://www.lcsc.com）で、部品番号 C5173310 を検索する。
  2. メーカーが WingTAT、型番が ED60BGFBK であることを確かめる。メーカー名の大文字・小文字の違いや、漢字の併記は同じとみなす。次のどれかなら止まる。似た部品は選ばない。
    • 型番が違う
    • 在庫が 3 個未満
    • 最小注文数や注文単位が、3 個と合わない
  3. 3 個をカートに入れる。単価は 1 個 約 1.36 米ドル（2026-11-14 の JLCPCB の部品データ）。
  4. 配送方法は、追跡番号の付く方法のうち、最も安いものを選ぶ。各方法の金額を控えておく。
  5. 上限と比べるのは、支払い画面に出る合計（部品・送料・手数料・前払いの税）。40 米ドル以下（円で表示されるときは 6,320 円以下）なら、確定して支払う。次のときは止まり、配送方法ごとの合計を報告する。
    • 上限を超える
    • 合計が画面に出ない
  6. 配達のときに配送業者が請求する税や手数料は、上限に入らない。これは依頼者が払う。GrokBOT は払わない。
  7. 届け先と支払い方法は、依頼者から受け取ったものを使う。

届いたあと、依頼者が次を確かめます（GrokBOT の作業ではありません）。

  • 端子の樹脂部分（幅 約 82.5 mm、奥行き 約 9.25 mm）が、カセットの殻の開口に入るか。
  • カセットの基板が 6.4 mm 以上入るか。
  • カセットを揺すっても、60 本すべての接触が保たれるか。

任天堂製と他社製を含む、数本のカセットで試します。

7. 依頼 3　Raspberry Pi Pico 2 の先行確保（依頼者は承認済み。在庫が増えたので、設計者が条件を付けた）

この基板は Raspberry Pi Pico 2（JLCPCB の部品番号 C41407547）を 1 枚に 3 個使います。試作 5 枚には 15 個が要ります。

JLCPCB の実装用の在庫は、2026-11-11 には 55 個でしたが、2026-11-14 には 480 個に増えていました。そのため、先行確保は在庫が減っているときだけ行います。

  • 依頼 3 は、依頼 1 の回答を待たずに行う。1f の回答が来ても、それだけで確保しない（回答は依頼者に報告する）。
  • 在庫の確認は、この指示書を読んで作業を始めるたびと、依頼 1 の回答を報告するときに行う。
  1. JLCPCB の部品ページ（https://jlcpcb.com/partdetail/C41407547）で、JLCPCB の在庫（In Stock）の数を読む。LCSC の在庫や、Global Sourcing の数は使わない。品名が Raspberry Pi Pico 2 であること（Pico 2 W や Pico 2 H ではないこと）を確かめる。
  2. 在庫が 100 個以上なら、買わない。在庫数と確認した日時を報告する。
  3. 在庫が 17 個以上 100 個未満なら、JLCPCB の部品の購入（在庫品を自分の部品庫に入れる。画面の表記は Pre-order や Order Parts など）で 17 個を買う（試作 5 枚分 15 個と予備 2 個）。
    • 合計が 160 米ドル以下なら、確定してよい。
    • 支払いは、カートに入れてから 1 時間以内に済ませる。過ぎると自動で取り消される。
    • 止まって承認を待つ間にカートが消えたら、入れ直して金額を確かめ直す。
  4. 在庫が 17 個未満なら、買わずに止まる。取り寄せになり、48 時間以内に金額が変わる（返金または追加の支払い）ことがあるため。
  5. 次のときも止まる。画面の文言をそのまま報告する。
    • 合計が 160 米ドルを超える
    • 保管料がかかると書いてある
    • 部品だけを送ってもらえると書いてある（下の説明と違う）
    • 返金や取り消しについて、下の説明と違うことが書いてある

JLCPCB の記事によると、買った部品は JLCPCB での部品実装にだけ使え、部品だけを別に送ってもらうことはできません。部品実装に使うかぎり、在庫の費用はかかりません。在庫は年に 0.03 % 目減りします。取り消しの記録は、Parts Order History の画面で見られます。

依頼者が「今すぐ確保して」と言った場合は、在庫が 17 個以上あれば、100 個以上でも 17 個を買ってかまいません（上限 160 米ドル）。

10. この基板について知っておくこと

  • 名前はファミコンアーキテクチャー基盤 rev 0.3 です。設計データの上では「ファミコン JAMMA 基板」（fcjamma）と呼んでいます。
  • ファミリーコンピュータの CPU と PPU を載せ替えて、業務用の筐体（JAMMA 規格）で動かす基板です。
  • 部品の実装は、すべて JLCPCB に任せます。端に金めっきの接点（金フィンガー）があるので、実装の種類は Standard PCBA になります。
  • 依頼者が自分で行う作業は 2 つだけです。ドナー機から外した CPU と PPU をソケットに挿すことと、USB でファームウェアを書くことです。
  • 同じ「異能ソフト」の中にある「ファミコン基板」と「ファミコン基板2」は、別の基板のフォルダです。
  • 旧フォルダ「ファミコン基板1」は使いません。
